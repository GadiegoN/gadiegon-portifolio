## 📌 Sobre o Projeto

Este projeto foi construído para funcionar como uma **apresentação profissional de alto impacto**, combinando a escaneabilidade de um currículo técnico com a profundidade de um portfólio interativo.

Apresenta o perfil multidisciplinar de **Gadiego de Jesus Nogueira**, integrando experiência sólida em:
- **Tecnologia & Desenvolvimento de Software**: Front-End moderno (React, Next.js, TypeScript) e Mobile (React Native, SQLite offline-first).
- **Análise & Suporte a Sistemas**: Sustentação de aplicações, atendimento a chamados de usuários e diagnóstico de falhas.
- **Processos, Compras & Operações**: Rotinas administrativas, acompanhamento de compras e contratos públicos e relacionamento com fornecedores.

---

## ✨ Principais Funcionalidades

- 🌐 **Internacionalização Bilíngue Completa (i18n)**:
  - Suporte nativo a **Português (BR)** e **English (US)** através do `next-intl`.
  - Seletor de idioma integrado no cabeçalho com persistência em cookie (`NEXT_LOCALE`) e transição instantânea.
- 🌓 **Design System com Tema Escuro e Claro**:
  - Paleta refinada **Midnight Navy & Violeta** desenvolvida com espaço de cores moderno **OKLCH**.
  - Alternância de tema suave e memorização de preferência via `next-themes`.
- 📱 **Mobile-First & Responsividade**:
  - Layout adaptado para visualização perfeita em telas de 360px até monitores ultrawide.
  - Menu drawer responsivo com acesso direto a todas as seções e download de arquivos.
- 📑 **Currículo Oficial em PDF Integrado**:
  - Botão de download direto do documento oficial em PDF em múltiplos pontos da navegação.
- 🚀 **SEO & Performance**:
  - Geração estática com Turbopack.
  - Metadados semânticos completos, Open Graph, `/sitemap.xml` dinâmico e `/robots.txt`.

## 🏛️ Estrutura das Seções

1. **Hero**: Apresentação com nome completo, headline profissional multidisciplinar, localização (*Conquista – MG*), disponibilidade, links para LinkedIn/GitHub e CTAs de ação rápida.
2. **Sobre**: Síntese profissional concisa explicando a intersecção entre engenharia de software e processos operacionais.
3. **Experiência Profissional**: Linha do tempo cronológica com as 6 experiências documentadas (Prefeitura de Conquista, Dyndo, Bravo Serviços Logísticos e SAAE).
4. **Projetos Selecionados**: Destaque principal para o app mobile **ShowUp** (arquitetura offline-first, persistência local em SQLite e sincronização com Supabase) e catálogo de aplicações web (**Snackfy**, **Guide City**, **FutPro**, **SaaS Agenda**, **Organize Birthday**).
5. **Competências & Tecnologias**: 4 categorias estruturadas sem métricas ou porcentagens arbitrárias (Tecnologia, Sistemas, Processos & Compras, Competências Interpessoais).
6. **Formação Acadêmica**: Bacharelado em Sistemas de Informação pela FAZU (2020).
7. **Contato & Rodapé**: Canais diretos de comunicação (LinkedIn, GitHub, WhatsApp e download de CV).

## 💻 Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 20 ou superior recomendada)
- Gerenciador de pacotes `npm`

### Passos

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/GadiegoN/gadiegon-portifolio.git
   cd gadiegon-portifolio
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   Abra [http://localhost:3000](http://localhost:3000) para visualizar a aplicação.

5. **Para gerar a build de produção:**
   ```bash
   npm run build
   npm run start
   ```
